# GravadorTelaWin — gravador de tela para Windows

> **Versão estável:** 2.5 RC2 homologada na `main`.
> **Versão de testes:** [2.6 RC1 — projetos e edição de textos](README_V26.md).

O aplicativo grava a janela visível do Chrome, monitor ou região, com áudio, webcam opcional, pausa/retomada e anotações sobrepostas (caneta, seta, retângulo, borracha, texto, cores, espessuras, desfazer/refazer). O processamento é local e os vídeos não são enviados à nuvem.

**Atalhos:** `Ctrl+Shift+R` inicia/termina, `Ctrl+Shift+P` pausa/retoma, `F8` ou `Ctrl+Alt+D` ativa desenho, com botão manual como alternativa.

A prévia 2.6 adiciona projetos de anotações `.gtwproj` e edição reversível de textos, sem alterar o motor de gravação ou áudio. Veja a [documentação](README_V26.md).

Código em Python/Tkinter/FFmpeg/Pillow, distribuído para Windows via GitHub Actions. Licença: [MIT](LICENSE).
